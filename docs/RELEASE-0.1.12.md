# 插件市场 0.1.12

这一版是对 PCL Harness **3.9.5** 的兼容性同步。最新插件 API 仍是 **v8**，没有新增 API 版本；市场代码无需功能改动，重新编译并在 3.9.5 上验证。

## 变更

- 使用 PCL Harness 3.9.5 开发包重新编译，确认现有安装、自更新、回滚、卸载、内置功能页兼容逻辑正常。
- 兼容 3.9.3+ 新增的宿主插件变更事件（`ModPlugin.PluginsChanged`）与内置市场安装入口；市场自身的旧宿主反射回退保持不变。
- `minApiVersion` 仍为 6，没有提高到 8，因此 3.7.3～3.9.5 的宿主都能继续使用。

## 兼容性

- PCL Harness 3.7.3+ / API v6+：完整功能。
- 3.9.0+ / API v8：下载/联机补位插件可正常安装、启用、停用。
- 3.9.5：已用最新开发包编译验证。

## 安装

从本 Release 下载 `pcl-harness-market-0.1.12.pclplugin`，在 PCL Harness 的「插件」页导入；或让已安装的 0.1.11 通过「插件市场」自更新。
