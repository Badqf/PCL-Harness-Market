# 插件市场 0.1.1

面向 PCL Harness 3.7.3+（插件 API v6）的更新版本。

## 这个版本做了什么

- **横向分类**：市场页顶部改为「发现 / 收藏 / 已安装 / 已禁用」四个分类标签，标签上显示数量，默认停在「发现」。
- **收藏**：每张卡片增加「☆ 收藏 / ★ 已收藏」，收藏列表保存在插件自己的 `data/favorites.txt`。选 `.txt` 而不是 `.json`，是为了不触发起动器对 `Plugins` 目录递归 `*.json` 的热重载。
- **本地插件列表**：如果插件已安装但不在索引里（自己导入的、索引下架的），也会出现在「已安装 / 已禁用」中，可直接启用、禁用、卸载。
- **下载量方案**：新增 `docs/DOWNLOAD-STATS.md`，给出一期（GitHub Release 资产计数 + Action 烘焙进索引）与二期（Cloudflare Worker + KV/D1）的完整方案；本版本**还没有显示下载量**，因为示例包仍走仓库直链，没有可用的计数源。

分类与收藏之外的行为（索引、镜像回退、SHA-256、安装默认不启用、Loaded 拦截、`net.dynamic`）与 0.1.0 一致。

## 安装

1. 下载本 Release 的 `pcl-harness-market-0.1.1.pclplugin`。
2. 打开启动器 →「插件」→「导入插件…」，选择该文件。
3. 导入后插件默认未启用，在插件列表里启用「插件市场」。
4. 标题栏出现「插件市场」入口；首次拉取 GitHub 索引时按提示允许网络访问。

已经安装 0.1.0 的用户：先禁用「插件市场」，关闭启动器，再用 0.1.1 包覆盖导入；导入后重新启用。

## 已知限制

- 运行中的插件无法热更新/热卸载：宿主用 `Assembly.LoadFrom` 加载 DLL，文件在进程退出前被锁定；市场会拦截并提示先禁用、重启启动器。
- 下载量尚未显示；方案见 `docs/DOWNLOAD-STATS.md`，需要先决定是否把插件包迁到 GitHub Release。
- 没有回滚、评分、评论、签名验证；SHA-256 只保证字节一致，不保证来源可信。
- 镜像由第三方提供，可用性不受本项目控制。
- 只支持 PCL Harness 3.7.3+；旧版没有 `plugins` 权限与管理 API。
