# 插件市场 0.1.14

这一版加快索引更新：Action 改为每 10 分钟同步，客户端缓存缩短到 3 分钟，索引优先走官方 raw、失败再自动回退镜像。

## 变更

- 索引缓存 TTL 从 10 分钟改为 3 分钟。
- 索引请求增加时间戳，避免 raw/CDN 的 5 分钟缓存让 3 分钟 TTL 失效。
- 索引顺序固定为「官方 raw → ghfast.top → gh-proxy.com」；raw 超时、被墙或报错时自动尝试下一个，不会因为某些地区访问 raw 而拿不到索引。
- 安装包和自更新仍优先使用镜像；设置里的「优先使用镜像」只影响下载，不影响索引顺序。
- GitHub Actions 的索引同步周期从 30 分钟改为 10 分钟。

## 兼容性

- PCL Harness 3.7.3+ / API v6+：完整功能。
- 索引下载失败时仍会回退到本地缓存，并在市场页显示警告。
- 旧宿主没有新增 API 时不受影响。

## 安装

从本 Release 下载 `pcl-harness-market-0.1.14.pclplugin`，在 PCL Harness 的「插件」页导入；或让已安装的 0.1.13 通过「插件市场」自更新。
