# 插件市场 0.1.13

这一版新增「可更新」分类，方便集中处理装过、但市场索引已有新版本的插件。

## 变更

- 首页分类标签在「已禁用」后新增「可更新」。
- 只显示已安装且本地版本低于索引最新版的插件；未安装、已是最新版的不显示。
- 计数与筛选都使用 `MarketText.CompareVersion`，和卡片上的「可更新」状态一致。
- 没有可更新插件时显示「市场里的插件都是最新版本。」

## 兼容性

- PCL Harness 3.7.3+ / API v6+：完整功能。
- 运行中的插件仍由宿主排队更新；需要重启生效时会显示提示与快速重启按钮。

## 安装

从本 Release 下载 `pcl-harness-market-0.1.13.pclplugin`，在 PCL Harness 的「插件」页导入；或让已安装的 0.1.12 通过「插件市场」自更新。
