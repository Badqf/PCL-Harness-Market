# 插件市场 0.1.15

这一版给索引加上启动器版本范围，让市场在插件与当前启动器不匹配时直接提示，而不是等安装后才失败。

## 变更

- 索引 `latest` 支持可选的 `minLauncher` / `maxLauncher`。
- 卡片在 `#标签` 后显示「适配 3.9.0 及以上」这类版本说明。
- 当前启动器不在范围内时：卡片变暗、显示红色提示，安装/更新按钮禁用，状态显示「不兼容当前启动器」。
- `make-index.ps1` 校验版本格式与上下限，并只把非空字段写入根索引。
- 现有索引补齐范围：AI 助手 3.8.3+、AI 助手 Pro 3.10.7+、下载/联机页面 3.9.0+。

## 兼容性

- PCL Harness 3.7.3+ / API v6+：完整功能。
- 旧宿主不支持 `minLauncher` 时字段被忽略，不影响原有安装流程。
- 不在范围内的插件仍可查看详情、卸载或回滚，只是不能安装/更新。

## 安装

从本 Release 下载 `pcl-harness-market-0.1.15.pclplugin`，在 PCL Harness 的「插件」页导入；或让已安装的 0.1.14 通过「插件市场」自更新。
