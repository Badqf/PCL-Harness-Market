# 插件市场 0.1.9

这一版修复市场与「插件」页之间的启用状态不同步。

## 修复

- 在市场卡片上启用或禁用插件后，已经打开过的「插件」页会继续显示旧的勾选状态。0.1.9 在操作成功后要求插件页重新读取状态，勾选立即同步。
- 卸载成功后也会同步刷新插件页，避免列表残留。
- 实现使用反射调用插件页的 `RefreshAfterImport()`，并投递到 UI 线程；旧宿主没有该页面或方法时静默跳过，不影响市场自己的状态刷新。

## 验证

- 已打开「插件」页 → 切到市场禁用 AI 助手 → 回到插件页，勾选变为「已禁用」。
- 再在市场启用 AI 助手 → 插件页立即变为「已启用」，计数同步更新。
- 0.1.8 的 AI 助手收录、API 版本门控、回滚、签名、下载进度与自更新行为不变。

## 兼容性

- `minApiVersion` 仍为 6；适配 PCL Harness 3.7.0+，API v7 能力继续按宿主反射降级。

## 安装

从本 Release 下载 `pcl-harness-market-0.1.9.pclplugin`，在 PCL Harness 的「插件」页导入；或让已安装的 0.1.8 通过「插件市场」自更新。
