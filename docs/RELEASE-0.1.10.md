# 插件市场 0.1.10

这一版修复「从市场安装后的插件在「插件」页列表里看不到、要重启才出现」的问题。

## 修复

- 安装成功后立即请求已打开的「插件」页重新读取插件列表；新插件无需重启即可出现在插件管理里。
- 刷新调用统一投递到 UI 线程，避免后台任务线程直接操作 WPF 页面导致刷新异常被宿主吞掉。
- 卸载、启用、禁用路径复用同一刷新逻辑，列表与勾选状态保持一致。

## 验证

- 打开「插件」页（共 11 个）→ 切到市场卸载「下载页面」→ 回到插件页，列表变为 10 个且条目消失。
- 再从市场安装「下载页面」→ 插件页立即恢复 11 个并出现该条目，无需重启。
- 启用「下载页面」「联机页面」后重启 3.9.0，`plugins.json` 保留两项，顶栏与插件页状态一致。

## 兼容性

- `minApiVersion` 仍为 6；适配 PCL Harness 3.7.0+，API v7 能力继续按宿主反射降级。
- 宿主没有 `PCL.ModMain.FrmPlugin` 或 `RefreshAfterImport()` 时静默跳过刷新，不影响市场自身状态。

## 安装

从本 Release 下载 `pcl-harness-market-0.1.10.pclplugin`，在 PCL Harness 的「插件」页导入；或让已安装的 0.1.9 通过「插件市场」自更新。
