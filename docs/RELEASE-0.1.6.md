# 插件市场 0.1.6

面向 PCL Harness 3.7.3+（插件 API v6）的兼容性与安全更新，重点适配 3.8.3 / API v7 的新能力。

## 这个版本做了什么

- **下载结果分类**：3.8.3+ 改用 `HttpDownloadResult`，区分未授权、主机拒绝、路径拒绝、超过 512 MB 与网络失败；失败时删除半截文件，提示更准确。旧宿主自动退回布尔版 `HttpDownload`。
- **回滚**：3.8.3+ 的已安装插件若有宿主备份，卡片右侧显示 `↶`；确认后回滚到上一版本，运行中的插件同样进入待生效队列。
- **签名状态**：详情里显示宿主读取的「未签名 / 已签名 / 无效 / 未知发布者」；市场不自行验证签名，也不会把签名当成可信度保证。
- **启用被拒绝提示**：3.8.3+ 对声明中/高风险权限的插件可能拒绝市场的启用请求；此时提示到「插件」页手动确认信任。
- **构建加固**：同步 SDK 3.8.3，校验 `vbc.exe` 的 Authenticode 签名、清单 DLL 只能是文件名且输出不越界；legacy vbc 的引用列表修正。
- **旧宿主兼容**：`minApiVersion` 仍为 6，新增 API 全部通过反射探测；3.7.3/3.7.4 上回滚与签名状态不显示，其余功能保持。

## 安装

1. 下载本 Release 的 `pcl-harness-market-0.1.6.pclplugin`。
2. 打开启动器 →「插件」→「导入插件…」，选择该文件。
3. 导入后插件默认未启用，在插件列表里启用「插件市场」。
4. 标题栏出现「插件市场」入口。

已经安装 0.1.5 的用户：可在市场页等待自更新提示，或直接导入本包；3.7.4+ 会进入待生效队列，重启后生效。
