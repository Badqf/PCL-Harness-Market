# 插件市场 0.1.5

面向 PCL Harness 3.7.3+（插件 API v6）的界面更新。功能与 0.1.4 一致，重点是列表可读性与操作密度。

## 这个版本做了什么

- **图标操作**：卡片右侧的收藏、安装/更新、启用/禁用、卸载、详情改为图标按钮；鼠标悬浮显示按钮名称。
- **横向操作区**：按钮从一列改为一行，状态文本与下载进度条仍在按钮上方。
- **卡片压缩**：间距与内边距收紧，折叠状态下的卡片高度明显下降；展开详情时仍显示完整说明、许可证、SHA-256 与主页链接。
- **索引设置**：测试环境已切回官方索引；默认安装仍是本仓库 `main/index.json`。

索引、镜像回退、SHA-256 校验、下载量、下载进度、3.7.4 待生效更新与市场自更新等行为与 0.1.4 一致。

## 安装

1. 下载本 Release 的 `pcl-harness-market-0.1.5.pclplugin`。
2. 打开启动器 →「插件」→「导入插件…」，选择该文件。
3. 导入后插件默认未启用，在插件列表里启用「插件市场」。
4. 标题栏出现「插件市场」入口。

已经安装 0.1.4 的用户：可在市场页等待自更新提示，或直接导入本包；3.7.4 会进入待生效队列，重启后生效。
