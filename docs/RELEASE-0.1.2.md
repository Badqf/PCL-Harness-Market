# 插件市场 0.1.2

面向 PCL Harness 3.7.3+（插件 API v6）的更新版本。

## 这个版本做了什么

- **只展示市场来源**：市场页只列出索引里的插件，不再把索引外的本地插件合成条目。「发现 / 收藏 / 已安装 / 已禁用」的数量也只统计索引条目；自己导入或已从索引下架的插件，请到启动器的「插件」页管理。
- **UI 重排**：分类标签、搜索框、刷新按钮与索引状态收进一张控制卡；卡片间距、字号与右侧操作区收紧，和启动器的卡片风格保持一致。
- **收藏位置**：收藏从卡片按钮改为右下角文字链「☆ 收藏 / ★ 已收藏」，不再占用主操作按钮的位置，并修正了对比度与底部留白。
- **文档**：`docs/DOWNLOAD-STATS.md` 保留下载量统计的两期方案；本版本仍未显示下载量，示例包仍走仓库直链，没有可用的计数源。

索引、镜像回退、SHA-256 校验、安装默认不启用、`PluginSummary.Loaded` 拦截与 `net.dynamic` 授权等行为与 0.1.1 一致。

## 安装

1. 下载本 Release 的 `pcl-harness-market-0.1.2.pclplugin`。
2. 打开启动器 →「插件」→「导入插件…」，选择该文件。
3. 导入后插件默认未启用，在插件列表里启用「插件市场」。
4. 标题栏出现「插件市场」入口；首次拉取 GitHub 索引时按提示允许网络访问。

已经安装 0.1.1 的用户：先禁用「插件市场」，关闭启动器，再用 0.1.2 包覆盖导入；导入后重新启用。

## 已知限制

- 运行中的插件无法热更新/热卸载：宿主用 `Assembly.LoadFrom` 加载 DLL，文件在进程退出前被锁定；市场会拦截并提示先禁用、重启启动器。
- 下载量尚未显示；方案见 `docs/DOWNLOAD-STATS.md`，需要先决定是否把插件包迁到 GitHub Release。
- 没有回滚、评分、评论、签名验证；SHA-256 只保证字节一致，不保证来源可信。
- 镜像由第三方提供，可用性不受本项目控制。
- 只支持 PCL Harness 3.7.3+；旧版没有 `plugins` 权限与管理 API。
